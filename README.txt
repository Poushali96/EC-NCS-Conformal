This is a validation-gated controlled confirmation, not proof that CQR is incapable of learning the mechanism.
All method choices, seeds and endpoints are locked in locked_config.json.
The gate uses training-only diagnostics; outer calibration and test labels never select the method.
A rejected candidate reverts exactly to Standard CP.
The rare label is defined from X before noise and is never selected using test residuals.
The explanation-aligned study is a controlled finite-sample boundary condition, not universal CQR dominance.
Oracle scale CP is unattainable and used only as a diagnostic lower bound.
Only Holm-adjusted tests may support comparative significance claims.
